# 待办便签 🐈

一个为 Windows 桌面打造的轻量待办便签，用 Electron 实现。它长得像一张便利贴：可以钉在桌面最顶层、调透明度、右下角还能贴一张你喜欢的图片当贴纸。

## ✨ 功能

- **永远置顶** —— 一键把便签钉在所有窗口上方，点哪都不消失
- **背景透明** —— 标题栏滑条调节，只透明背景，文字始终清晰
- **待办管理**
  - 双击横线直接输入新任务
  - 点左侧小方框勾选完成，该行划掉并自动沉到底部
  - 右键任务可编辑 / 删除，右键"已完成"可一键清除
  - 底部进度条 + `完成/总数` 计数
- **贴纸（个性化）** —— 把任意图片（包括 GIF！）贴到便签右下角当花纹
  - 大小 / 浓度可调
  - 三种样式：原图、圆角、相纸（白边+投影）
  - **融合模式**：白底图片"印"进纸张里，几乎看不出是贴上去的
  - **镜像**：一键左右翻转
  - 面板展开时可直接按住贴纸拖动位置
  - 横线自动避让贴纸，不会画到图上面
- **便携免安装** —— 一个 exe 文件，数据存在旁边的 `data.json` 里
- 单实例运行，任务栏有可爱的猫猫图标 🍈

## 🚀 使用

1. 下载或克隆本仓库
2. 按 [打包](#-打包) 生成 `待办便签.exe`（或直接 `npx electron .` 运行）
3. 双击启动，开始写你的待办！

所有数据（任务、贴纸、样式、位置）自动保存在 exe 同目录的 `data.json`，删掉程序也不会丢历史。

## 🔧 打包

本项目无需打包工具，Electron 便携版只需三步：

```bash
npm install          # 安装 electron
# 1. 复制 node_modules/electron/dist/ 整个目录，改名为「待办便签」
# 2. 在其中新建 resources/app/ 文件夹，放入本仓库的全部源码
# 3. （可选）用 rcedit 给 exe 换上 cat.ico 图标
```
